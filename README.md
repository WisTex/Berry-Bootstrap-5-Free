# Berry Free Bootstrap 5 Admin Template
by Coded Themes

This is our own reference copy of the Berry theme. We use this on some of our websites and use it as a Hubzilla theme (in modified form). This repo is not a substitute for obtaining it from the source. 

You can download the latest version directly from Coded Themes, and even buy the pro version from them. They have other themes too. 

https://codedthemes.com/item/berry-bootstrap-free-admin-template/
